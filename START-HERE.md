# С чего начать

1. **Запуск:** откройте `index.html` в браузере (Chrome, Edge, Firefox) — игра готова,
   ничего устанавливать не нужно.
2. **`docs/HANDOFF.md`** — главный документ: архитектура, баланс, что сделано,
   тесты и что осталось (только push в git).
3. **`README.md`** — описание проекта, скриншоты, структура и команды проверки.
4. **`docs/CONVERSATION.md`** — сохранённая переписка, по которой собирался проект.

## Проверки

```bash
node tests/run.js          # 29 юнит-тестов логики
node tools/balance.js      # симуляция баланса: все 3 карты проходятся
node tools/ui-check.js     # 24 проверки интерфейса в headless-браузере
```
